# Privacy Policy

**KJV Reader's Bible** — last updated 7 November 2026

KJV Reader's Bible does not collect, store or share any personal information.

## What stays on your computer

Everything you create in the app — highlights, bookmarks, notes, playlists, imported slides and settings — is saved only on your own computer. None of it is sent anywhere.

## Network use

The app works fully offline. The only time it connects to the internet is to check for updates: it downloads a small file (`latest.json`) from this project's GitHub releases page and, if you choose to install an update, the new installer from the same place. No personal data, usage data or identifiers are sent with these requests. GitHub may log the request as it does for any download; see [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## No tracking

The app has no analytics, telemetry, advertising or crash reporting.

## Contact

Questions about this policy can be raised as an issue at <https://github.com/Johnstands/bible-app/issues>.
